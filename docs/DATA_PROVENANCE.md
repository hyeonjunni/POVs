# 데이터 출처와 공개 검토 상태

이 문서는 시연용 미디어의 제작 도구와 공개 가능 여부를 검토한 현황을 정리합니다. **현재 이 저장소에는 원본 데이터(이미지·영상·음성)와 그 대본·메타데이터가 포함되어 있지 않습니다.**

## 제작 도구 (제작자 진술 기준)

아래 내용은 제작자의 진술을 옮긴 것이며, 파일 단위로 검증하지 않았습니다. 이 진술만으로 데이터가 완전히 합성된 것인지, 권리가 확보되었는지, 공개해도 되는지는 판단할 수 없습니다.

| 종류 | 도구 | 확인 상태 |
|---|---|---|
| 이미지 | ChatGPT | 사용한 정확한 모델은 확인하지 못함 |
| 영상 | Sora | 제작자 진술 |
| 음성 | Typecast | 유료 플랜으로 다운로드(사용자 확인). 세부 플랜·다운로드일·캐릭터 미확인 |

ChatGPT·Sora 이용 조건은 이 문서에서 아직 검토하지 않았습니다.

## Typecast 공식 자료 (2026-11-08 확인)

| 자료 | 관련 내용 |
|---|---|
| [출처 표기 안내](https://typecast.ai/kr/guideline/) | 무료 플랜으로 개인 온라인 채널(유튜브 등)에 올릴 때 출처 표기가 필요합니다. 설명 문구, 사용한 캐릭터 이름 전부, 홈페이지 URL(`https://typecast.ai`)을 모두 넣어야 합니다. 영상 없이 오디오만 쓰면 콘텐츠 시작 부분에 출처 안내 음성을 넣습니다. 유료 플랜은 출처 표기 없이 사용할 수 있다고 안내합니다. 파일 재배포나 데이터셋은 다루지 않습니다. |
| [이용약관](https://help.typecast.ai/ko/articles/17346794-이용약관-26-09-01-26-11-17) | 제2조 제2항: 구독 기간 중 생성·다운로드한 이용자 생성 파일의 소유권을 이용자에게 부여하고, 구독이 끝난 뒤에도 기존 파일 사용에 제약이 없다고 정합니다. 제4조 제4항 제3호: 외부에 공개·배포할 때 AI로 생성되었음을 명시해야 합니다. 2026-11-08 현재 적용되는 2026-09-01~11-17 판을 확인했습니다. |

## 쟁점

- **유튜브 게시와 GitHub 재배포는 다릅니다.** 출처 표기 안내는 완성된 콘텐츠를 채널에 올리는 경우를 다룹니다. GitHub 공개 저장소에 raw 음성 파일을 두면 누구나 clone·download해 다른 용도로 쓸 수 있으므로, Usage policy의 단독 파일 배포 조항과 겹칠 수 있습니다.
- **약관과 Usage policy의 관계가 불분명합니다.** 약관은 "소유권 부여"를, Usage policy는 "양도 불가 사용권"을 말합니다. 두 문서의 적용 범위가 어떻게 조정되는지 공식 자료에서 확인하지 못했습니다.
- 위 자료만으로는 GitHub 재배포가 금지된다고도, 허용된다고도 판단하지 않습니다.

## 공개 전 확인할 것

1. 유료 플랜의 세부 이름, 다운로드 시점, 사용 캐릭터
2. Typecast에 GitHub 공개 데이터셋 형태의 재배포 가능 범위와 출처 표기 조건 문의
3. 실제 파일(대본·메타데이터 포함) 내용 검토
4. ChatGPT·Sora 산출물의 이용 조건 검토

## 현재 결정

- 원본 음성은 권한 확인 전까지 공개하지 않습니다.
- 음성 대신 대본이나 메타데이터만 공개하는 방안도 실제 파일 검토 전에는 보류합니다.
- 이미지·영상도 현재 포함하지 않았습니다.
