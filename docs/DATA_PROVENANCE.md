# 데이터 출처

이 문서는 `datasets/demo/`에 포함된 시연 자료의 구성과 제작 도구를 정리합니다.

## 구성

가상 가족 4인(F1~F4)을 위한 합성 시연 자료입니다. 가족 구성원과 가족 사건은 가상으로 구성했습니다.

| 구분 | 건수 | 형식 | 폴더 |
|---|---:|---|---|
| 가족 사진 | 18 | PNG | `images/` |
| 가상 건강검진 결과표 | 8 | PNG | `images/` |
| 음성 | 13 | WAV (44.1kHz, 모노) | `audio/` |
| 텍스트(일기·메모) | 103 | UTF-8 TXT | `text/` |
| **원본 자료 합계** | **142** | | |
| 사건 메타데이터 | 49 | UTF-8 TXT | `events/` |
| 영상 | 0 | | |

- 사건 메타데이터 49건은 원본 자료 142건과 별도로 집계합니다. 사진 설명, 음성 대본, 사건 설명은 텍스트 103건에 중복 합산하지 않았습니다.
- `text/`와 `events/`의 TXT는 적재 계획의 제목과 본문을 배포용으로 저장한 파일입니다(첫 줄 제목, 빈 줄, 본문).
- `자료목록.csv`에는 191건(원본 자료 142 + 사건 메타데이터 49)의 자료 ID, 제목, 형식, 관리 소유자, 적재 당시 공개 범위, 발생일, 파일 경로, SHA-256이 있습니다. 포함된 파일은 모두 이 체크섬과 일치합니다.
- `owner`는 자료를 관리하는 가상 구성원이며 작성자와 같은 뜻으로 보지 않습니다.

## 제작 도구

| 구분 | 제작 방식 |
|---|---|
| 가족 사진 18건 | ChatGPT 이미지 생성. 각 파일의 C2PA 메타데이터(AI 생성 표시)를 유지했습니다. |
| 건강검진 결과표 8건 | 가상 인물용으로 제작한 문서 이미지. 이미지 안에 "가상 기관 · 실제 의료서류 아님"을 표기했습니다. |
| 음성 13건 | [Typecast](https://typecast.ai) 유료 플랜으로 생성한 AI 합성 음성입니다. |
| 영상 | 포함하지 않았습니다. |

이미지와 음성 파일은 이 저장소에 담으면서 압축하거나 변환하지 않았습니다.

## 공개 범위 값(PRIVATE / FAMILY)

`자료목록.csv`의 `visibility_at_import`(PRIVATE 131건, FAMILY 60건)는 가상 가족 구성원 사이의 공개 범위와 권한 검사를 시험하기 위한 값입니다. 실제 개인의 비공개 정보가 아니며, 공개 저장소에 있으므로 누구나 내용을 볼 수 있습니다. 앱에 올려 권한 동작을 재현할 수 있도록 값을 그대로 두었습니다. 이 값은 적재 시점 기준이며, 이후 앱에서 바꾼 공개 범위를 반영하지 않습니다.

## 포함하지 않은 것

- 질의·응답 평가 질문셋(4,338건)과 시연 자료를 가공한 학습·평가 데이터, 생성 예시
- 운영 DB, 암호화 키, 로그인 정보, 환경 파일, 모델 가중치·어댑터
- 운영 서비스 복원용 백업. `datasets/demo/`는 서비스 재적재용 백업이 아닌 원본 자료 묶음이며, 앱 자동 적재는 구현되어 있지 않습니다(README의 "앱에 직접 올려 보기" 참고).

이 저장소는 시연 자료에 별도 라이선스를 부여하지 않습니다. 저작권 관련 내용은 README의 "저작권과 라이선스"를 따릅니다.
